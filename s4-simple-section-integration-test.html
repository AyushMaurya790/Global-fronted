Testing the integration of simple-section API for Group Tours section

API Endpoint Information

Endpoint: http://globe.ridealmobility.com/api/simple-section/country/68c00412cd2575bd4c46121b

Method: GET

Country: New Zealand (ID: 68c00412cd2575bd4c46121b)

Purpose: Fetch simple section cards for Group Tours section

Target Section: Group Tours (#group-tours) in s4.html

Integration Flow

  1. User navigates to s4.html (New Zealand destination page)
  2. Page loads and automatically fetches simple-section data from API
  3. Static Group Tours cards are replaced with dynamic API content
  4. Cards show images and titles from API with generated tour details
  5. Swiper slider maintains functionality with new cards
  6. If fewer than 6 cards from API, default cards fill remaining slots
