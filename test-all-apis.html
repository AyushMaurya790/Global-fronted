How to test in GroupTours.html:

  1. Open GroupTours.html in your browser
  2. Open Developer Tools (F12) → Console tab
  3. Run these commands to test individual APIs:
    • testTripInspirationAPI() - Test Trip Inspiration
    • testBestTimeAPI() - Test Best Time to Visit
    • manualTripInspirationInit() - Manual Trip Inspiration init
    • manualBestTimeInit() - Manual Best Time init
